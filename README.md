README - Interactive Soundscape Wheel.

The interactive soundscape wheel is part of an academic research effort by members of the Nordic Soundscape Research Network. This network consists of a diverse group of soundscape researches, from eco-acousticians to social scientists. 

Inspired by the landscape character assessment wheel, members of the network led an effort to create a soundscape wheel which can be used for soundscape character assessment and education on soundscape research. 

The resulting paper on the soundscape wheel is published in Tourism Geographies (Keller, R., Wilsnach, N., Ruiz-Arana, U., Cerwén, G., Martin, J., Van Bendegom, C., & Hu, Y. (2026). The soundscape wheel: a conceptual map for tourism geographers. Tourism Geographies, 1–19. https://doi.org/10.1080/14616688.2026.2741193). Additionally, two of the co-authors of the paper have continued to develop the soundscape wheel into an interactive tool. Based on the manuscript, this tool provides brief explanations and key references to each of the elements of the soundscape wheel. The soundscape wheel is applied to Femundsmarka National Park in Norway and includes sound clips recorded there.

The interactive soundscape wheel can be used and edited with credit to the authors. We encourage students and academics interested to work with the soundscape wheel and its interactive version. Audio clips and images can be edited for application to cases of interest.


Suggested reference: van Bendegom, C. & Wilsnach, N. (2026). Interactive Soundscape Wheel (Version 1.0.0) [Software]. Zenodo.https://doi.org/10.5281/zenodo.22893474.)

//HOW TO EDIT.

REPLACE AUDIO FILES
Replace an audio file in the 'audio' folder with your audio. This has to be a .mp3 or .wav file. The name of the audio file that is replaced needs to be exactly the same, for example 'anthrophony-socialcultural'. Currently the wheel is set-up for .mp3 files, but this can be changed in the code by opening the HTML file with the Notepad (on Windows).

EDIT THE WHEEL
Open the HTML file with the Notepad (on Windows). Scroll down or use CTRL+F to find 'edit content'. Change the description and credit here if needed. When using a .wav audio file, replace the .mp3 for .wav in the code. You can also change the description and credit for the audio files. To change the image CTRL+F 'images' and replace femundsmarka.jpg with the name of the image file you've replaced the femundsmarka.jpg file with.
